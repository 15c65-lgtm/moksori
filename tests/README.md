# 자동 점검

```
python3 tests/run.py
```

- 시험용 소리(합성 모음, 말소리 비슷한 소리, 음계 노래)를 `tests/fixtures/`에 만들고, 로컬 서버를 띄워 크롬으로 점검해요.
- 점검 항목: 모든 페이지 열림·오류·폰 화면 넘침, 울림 재기(남자/여자 「아」), 공채 EBS 파일 나누기, 노래 채점, 대본 표시·녹음, 같이 읽기(같은 브라우저 탭 두 개), 「이상해요」 알림.
- 사람 녹음은 공개 저장소라 넣지 않아요. 실제 녹음 점검은 기기 안에서 따로 해요.
- 올리기 전에 항상 돌려서 전부 통과하는지 확인해요.
